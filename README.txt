ЛОКАЛЬНЫЙ АГЕНТ: ЧАТ + КАРТИНКИ
================================

Что это: помощник, который работает целиком на твоём компьютере, без подписок и без интернета
(интернет нужен только для установки). С ним можно разговаривать и просить нарисовать картинки
(аниме, иллюстрации, персонажи, пейзажи). Окно открывается в браузере.

ЧТО НУЖНО
- Windows 10 или 11 (64 бит)
- Видеокарта NVIDIA с 12 ГБ видеопамяти (например, RTX 3060 12 ГБ, RTX 4070 и новее) и свежий драйвер
- 16 ГБ оперативной памяти
- Около 40 ГБ свободного места во время установки (потом агент занимает ~22 ГБ)
- Интернет: скачается около 15 ГБ

УСТАНОВКА
1. Распакуй архив в любую папку.
2. Дважды щёлкни Install.bat.
   Если Windows покажет синее окно «Система Windows защитила ваш компьютер» —
   нажми «Подробнее» → «Выполнить в любом случае».
3. Нажми Enter, чтобы поставить в предложенную папку (или впиши свою), и жди.
   Если интернет оборвётся — просто запусти Install.bat снова, скачивание продолжится.
4. В конце на рабочем столе появится ярлык «Агент».

ЗАПУСК
Ярлык «Агент». Откроется окно в браузере. Чёрное окно «Агент» и свёрнутое окно ComfyUI
не закрывай, пока пользуешься агентом. Первый запуск — минута-две.
Картинки сохраняются в папку images (кнопка «Папка с картинками» в окне).

УДАЛЕНИЕ
Файл uninstall.bat в папке, куда поставлен агент.

ЧТО СТАВИТСЯ (всё из официальных источников)
- Ollama (ollama.com) — программа для модели чата
- Модель чата Qwen3.5-9B «The Defiant Fable» (DavidAU, Hugging Face), лицензия Apache-2.0.
  Модель без цензуры: отвечает на любые темы — учитывай это.
- ComfyUI (github.com/Comfy-Org/ComfyUI) — программа для рисования
- Модель рисования Anima (circlestone-labs, Hugging Face): лицензия только для НЕКОММЕРЧЕСКОГО
  использования самой модели; нарисованные картинки использовать можно.
