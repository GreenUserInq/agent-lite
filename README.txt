ЛОКАЛЬНЫЙ АГЕНТ: ЧАТ + КАРТИНКИ
================================

Что это: помощник, который работает целиком на твоём компьютере, без подписок и без интернета
(интернет нужен только для установки). С ним можно разговаривать и просить нарисовать картинки
(аниме, иллюстрации, персонажи, пейзажи). Окно открывается в браузере.

ЧТО НУЖНО
- Windows 10 или 11 (64 бит)
- Видеокарта NVIDIA с 12 ГБ видеопамяти (например, RTX 3060 12 ГБ, RTX 4070 и новее) и свежий драйвер
- 16 ГБ оперативной памяти
- Около 45 ГБ свободного места во время установки (потом агент занимает ~30 ГБ)
- Интернет: скачается около 24 ГБ

УСТАНОВКА
1. Распакуй архив в любую папку.
2. Дважды щёлкни Install.bat.
   Если Windows покажет синее окно «Система Windows защитила ваш компьютер» —
   нажми «Подробнее» → «Выполнить в любом случае».
3. Нажми Enter, чтобы поставить в предложенную папку (или впиши свою), и жди.
   Если интернет оборвётся — просто запусти Install.bat снова, скачивание продолжится.
4. В конце на рабочем столе появится ярлык «Агент».

ЗАПУСК
Ярлык «Агент». Откроется окно в браузере. Чёрное окно «Агент» и свёрнутое окно ComfyUI
не закрывай, пока пользуешься агентом. Первый запуск — минута-две.
Картинки сохраняются в папку images (кнопка «Папка с картинками» в окне).

МОДЕЛИ ЧАТА (список в шапке окна, у каждой беседы своя)
- Gemma 4 12B — работа: аккуратная и быстрая, но с обычными ограничениями (на откровенное откажет).
- Gemma 4 12B — без цензуры: отвечает на любые темы, но чаще ошибается и иногда пишет «готово», когда не вышло.
Переключение между моделями — несколько секунд (в видеокарту помещается одна).

ДОКУМЕНТЫ WORD
Попроси «сделай документ …», «найди в интернете … и сохрани в ворд», «исправь в документе … (путь)» — агент создаёт и правит
.docx (каждую правку подтверждаешь, копия до правки — в папке doc_backups). Без пути документ ляжет в папку documents.
Под ответом появятся кнопки «Открыть» и «Показать в папке». Старый формат .doc и сохранение в PDF — если установлен Microsoft Word.

ИНТЕРНЕТ: СВОЙ БРАУЗЕР АГЕНТА
Попроси «загугли …», «найди в интернете …», «открой сайт …» — агент откроет СВОЙ Chrome (отдельное окно,
чистый профиль в папке browser_profile: твоих вкладок, почты и паролей он не видит), поищет в Google и прочитает страницы.
Если сайт покажет капчу «я не робот», агент остановится и попросит: пройди её в окне его браузера и напиши «готово».
В банки, почту и на страницы входа агент не ходит, пароли не вводит, кнопки «оплатить / купить / отправить» — только с твоего разрешения.
Нужен установленный Google Chrome (или Microsoft Edge).

УПРАВЛЕНИЕ ПК (выключено, пока не включишь)
Внизу слева «Управление ПК» → «Включить». Тогда агент сможет делать снимки экрана, видеть окна и — с твоего разрешения
на каждую задачу — нажимать и печатать в Блокноте, Paint, Word, Excel, Калькуляторе и Проводнике.
Остановить в любой момент: красная полоса «СТОП» сверху экрана, клавиша Pause, Ctrl+Alt+S или просто двинь мышь.
Окна банков, почты и паролей — под запретом. Выключить — той же кнопкой.

ПОМОЩЬ С КОДОМ (необязательно)
Агент может читать и править код в папке твоего проекта (например, игры на Unity).
1. Внизу слева «+ Папка проекта» → выбери папку проекта. Агент видит ТОЛЬКО подключённые папки.
2. Попроси в беседе: «в проекте добавь …», «найди, где …», «почему не компилируется …».
3. Каждую правку файла агент показывает и ждёт кнопку «Выполнить» — можно отклонить.
Чтобы правки можно было откатить, папка должна быть git-репозиторием (нужен Git с git-scm.com
и хотя бы один коммит). Без него агент только читает и ищет.
Перед первой правкой агент сам делает снимок папки в служебную ветку git agent/<дата>-<задача>
(твою ветку и файлы он не переключает и не коммитит). Кнопка «Откатить» у проекта вернёт файлы
к снимку, «Изменения» — покажет, что поменялось.
Для проектов Unity агент проверяет, что код компилируется (нужен .NET SDK с dotnet.microsoft.com
и хотя бы раз открытый в Unity проект). Файлы .meta, сцены и префабы он не трогает.
Модели этого размера хорошо справляются с мелкими правками (поле, метод, исправить ошибку),
большие переделки через много файлов — пока плохо. Проверяй результат в своей программе.

УДАЛЕНИЕ
Файл uninstall.bat в папке, куда поставлен агент.

ЧТО СТАВИТСЯ (всё из официальных источников)
- Ollama (ollama.com) — программа для модели чата
- Модели чата из библиотеки Ollama: Gemma 4 12B (Google, лицензия Gemma) и её версия без цензуры
  huihui_ai/gemma-4-abliterated (отвечает на любые темы — учитывай это).
- ComfyUI (github.com/Comfy-Org/ComfyUI) — программа для рисования
- Модель рисования Anima (circlestone-labs, Hugging Face): лицензия только для НЕКОММЕРЧЕСКОГО
  использования самой модели; нарисованные картинки использовать можно.
