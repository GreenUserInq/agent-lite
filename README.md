# Локальный агент: чат + картинки

Помощник, который работает целиком на твоём компьютере: с ним можно разговаривать и просить нарисовать картинки
(аниме, иллюстрации, персонажи, пейзажи). Окно открывается в браузере. Интернет нужен только для установки и обновлений.

## Установка

1. Нажми зелёную кнопку **Code → Download ZIP** и распакуй архив.
2. Дважды щёлкни `Install.bat` (если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае»).
3. Нажми Enter и жди: скачается около 24 ГБ. Оборвался интернет — запусти `Install.bat` снова, скачивание продолжится.
4. Запуск — ярлык **«Агент»** на рабочем столе.

Подробности, требования и лицензии моделей — в [README.txt](README.txt).

**Нужно:** Windows 10/11, видеокарта NVIDIA с 12 ГБ видеопамяти, 16 ГБ оперативной памяти, ~45 ГБ свободного места на время установки.

## Документы, интернет и управление ПК

- **Документы Word:** «сделай документ …», «найди в интернете … и сохрани в ворд», «исправь в документе …» — создание и правка .docx с подтверждением (копия до правки в `doc_backups`), кнопки «Открыть» / «Показать в папке». `.doc` и PDF — если установлен Microsoft Word.

- **Свой браузер агента:** «загугли …», «открой сайт …» — агент ищет в Google и читает страницы в отдельном Chrome с чистым профилем (твоих вкладок и паролей он не видит). Капчу проходишь ты, агент ждёт «готово». Нужен Google Chrome или Edge.
- **Управление ПК** — выключено, включается внизу слева. Снимки экрана, окна, а с разрешения на каждую задачу — нажатия и печать в Блокноте, Paint, Word, Excel, Калькуляторе, Проводнике. Стоп: полоса «СТОП» сверху, Pause, Ctrl+Alt+S или движение мыши.

## Помощь с кодом (необязательно)

Внизу слева **«+ Папка проекта»** — подключить папку проекта (например, игры на Unity). Агент видит только подключённые папки: ищет, читает, правит (каждую правку подтверждаешь кнопкой), для Unity проверяет сборку (нужен .NET SDK). Откат — кнопка **«Откатить»** у проекта: перед первой правкой агент делает снимок папки в служебную ветку git `agent/...`, поэтому папка должна быть git-репозиторием (без Git — только чтение). Подробнее — в [README.txt](README.txt).

## Обновления

Кнопка **«Обновления»** внизу слева в окне агента. Обновляется только окно агента; беседы, картинки и модели остаются. Если в новой версии появились новые модели, окно докачает их само (прогресс — внизу слева).
